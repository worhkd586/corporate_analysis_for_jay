# 메자닌 투자 전 기업분석 체크리스트

CB(전환사채)·BW(신주인수권부사채)·EB(교환사채) 투자자가 투자 전에 확인하는 항목과 우선순위입니다.
대시보드(`index.html`)의 점수는 이 표를 기준으로 계산합니다.

메자닌의 수익 구조는 **하방은 채권(풋옵션·만기보장수익률), 상방은 주식(전환)** 입니다.
그래서 "돌려받을 수 있는가"를 먼저 보고, "얼마나 벌 수 있는가"는 그다음에 봅니다.

| 우선순위 | 항목 | 가중치 | 왜 보는가 | 확인 지표 |
|---|---|---|---|---|
| P1 | 상환능력·유동성 | 25% | 풋 행사 시 원리금 회수 가능성 = 하방 | 현금 vs 단기차입금+메자닌 잔액, 영업현금흐름, 이자보상배율, 담보 가능 자산 |
| P1 | 주가·전환가치 | 20% | 업사이드와 회수 경로 | 현재가 vs 전환가, 52주 고저·변동성, 일평균 거래대금, 리픽싱 하한 |
| P1 | 오버행·희석 | 15% | 기발행 물량이 전환가치를 훼손 | 미상환 메자닌/시가총액, 잠재 희석률, 반복 발행 여부 |
| P2 | 재무건전성·상장유지 | 15% | 거래정지 시 회수 불가 | 부채비율, 자본잠식, 감사의견, 관리종목 이력 |
| P2 | 지배구조·최대주주 | 10% | 메자닌 부실의 대표 신호 | 최대주주 지분·주식담보, 최대주주 변경, 콜옵션 대상, 횡령·불성실공시 |
| P3 | 사업성·성장성 | 8% | 주가 상승의 근거 | 매출 성장률, 영업이익률, 자금 사용 목적, 업황 |
| P3 | 밸류에이션 상대수준 | 7% | 전환 후 상승 여력 | PER·PBR·EV/EBITDA vs 경쟁사 중앙값, PSR |

## 판정 규칙

- 각 항목 1~5점, 가중 평균을 100점으로 환산
- **P1 항목 중 하나라도 1점이면 점수와 관계없이 "투자 보류"**
- 70점 이상: 투자 검토 가능 / 50~69점: 조건부 검토(담보·이자율·콜옵션 조건 보완) / 50점 미만: 부적합

## 정성평가 · 특이사항

숫자로 일률화하기 어려운 항목은 점수에 넣지 않고 따로 점검합니다. "Claude 정성평가 실행"을 누르면 DART 재무·메자닌 조건·감사의견과 **최근 2년 공시 목록**을 근거로 항목별 상태(위험/주의/확인 필요/양호), 근거 공시 링크, 원문에서 확인할 것을 정리합니다. 결과는 대시보드 저장소(`qual/<corp_code>`)에 저장돼 다시 열면 바로 보입니다.

| 항목 | 보는 것 |
|---|---|
| 상장유지·관리종목 리스크 | 법차손, 매출 요건, 기술특례 유예 종료 시점 |
| 주가연계 파생·특수 계약 | PRS·TRS, 자기주식 교환·처분, 콜옵션·매도청구권 |
| 기존 메자닌 조건 특이사항 | 인수자, 리픽싱·풋 일정, 중도상환 |
| 감사의견·회계 이슈 | 강조사항, 계속기업 불확실성, 감사인 교체 |
| 최대주주·지배구조 | 지분 담보, 최대주주 변경, 특수관계자 거래 |
| 소송·제재·불성실공시 | 소송 규모, 벌점, 횡령·배임 |
| 자금조달·현금 소진 | 반복 조달, 자금 사용처, 현금 소진 기간 |
| 사업·파이프라인 이벤트 | 기술이전 계약, 임상·인허가, 매출 의존 |

정성평가에서 "위험"이 나오면 종합 판정 옆에 건수를 표시하고, 종합이 "투자 검토 가능"이어도 주의로 낮춥니다.

Claude 호출 없이 바로 보이는 것:
- **상장유지 요건 간이 점검**: 연도별 법차손(법인세비용차감전손실)/자기자본, 매출 30억 미만, 연속 영업손실, 자본잠식 (코스닥 관리종목 요건을 단순화한 것. 기술특례 유예는 정성평가에서 확인)
- **공시 키워드**: 최근 2년 공시 제목을 메자닌 발행, 최대주주 변경, 담보, 파생·PRS, 소송, 관리종목 등으로 분류
- **현금 소진 기간**: 현금 ÷ 연간 영업현금 유출

## 발행조건 시뮬레이터

- 패리티 = 현재 주가 / 전환가액
- 리픽싱 후 최저 전환가 = 전환가액 × 리픽싱 하한(통상 70%)
- 풋 시점 상환액 = 100 × (1 + 만기보장수익률)^(풋 시점) − 표면이자 누적분 (단순화한 근사치)
- 풋 대비 전환이 유리한 주가 = 전환가액 × 풋 시점 상환액 / 100

## 데이터 한계

재무제표·메자닌 발행이력·최대주주 지분은 DART 공시, 주가는 네이버 증권 시세(수집 시점 종가)에서 가져오지만, 경쟁사·정성평가와 DART에 저장되지 않은 기업의 분석은 Claude가 학습한 공개 정보로 만든 **추정치**입니다.
투자 판단 전에 다음 원문으로 확인해야 합니다.

- 최신 사업보고서·분기보고서 (재무제표, 감사의견)
- 주요사항보고서: 전환사채권/신주인수권부사채권 발행결정 (기발행 메자닌 조건)
- 최대주주 등 소유주식 변동신고, 주식등의 대량보유상황보고서 (담보 계약)

## DART 데이터 연동

DART 데이터가 없는 기업을 검색하면 **DART 수집 요청** 버튼이 나옵니다. 누르면 요청이 대시보드 저장소에 쌓이고, Claude Code 세션에서 "대기 중인 DART 요청 처리해"라고 하면 `scripts/dart_fetch.py`가 한꺼번에 받아 올립니다(절차는 `CLAUDE.md`). 대시보드를 열어 두면 처리가 끝나는 대로 화면이 바뀌고, 한 번 받은 기업은 다음부터 바로 표시됩니다.

저장소 구조: `companies/<corp_code>`(기업 데이터), `qual/<corp_code>`(정성평가 결과), `lookup/n_<정규화한 이름의 UTF-8 hex>`·`lookup/t_<종목코드>`(검색어 → corp_code), `results/<요청 id>`(완료 신호).

`scripts/dart_fetch.py`가 DART OpenAPI에서 가져오는 항목:

| 항목 | DART API |
|---|---|
| 기업개황 | `company.json` |
| 최근 5개년 재무제표(연결 우선), 최신 분기 대차대조표 | `fnlttSinglAcntAll.json` |
| CB·BW·EB 발행결정(최근 4년) | `cvbdIsDecsn.json`, `bdwtIsDecsn.json`, `exbdIsDecsn.json` |
| 최대주주 지분 | `hyslrSttus.json` |
| 발행주식수(시가총액 계산용) | `stockTotqySttus.json` |
| 최근 2년 공시 목록(정성평가 근거) | `list.json` |
| 감사인·감사의견 | `accnutAdtorNmNdAdtOpinion.json` |
| 주가(현재가, 52주 고저, 20일 평균 거래대금, 변동성, 24개월 월말 종가) | 네이버 증권 `siseJson` (DART에는 주가가 없음) |

- DART 데이터가 있는 기업은 Claude 호출 없이 표시하고, 상환능력·재무건전성 점수는 규칙으로 자동 계산합니다.
- 경쟁사·나머지 점수는 "Claude로 채우기", 정성평가는 "Claude 정성평가 실행" 버튼을 누를 때만 요청합니다. "Claude로 채우기"는 DART 숫자를 프롬프트에 요약만 넣고 응답으로 다시 받지 않습니다.
- 주가는 수집 시점 종가라 시간이 지나면 오래된 값이 됩니다. 같은 기업을 다시 수집 요청하면 갱신됩니다. 시세를 받지 못한 기업만 Claude 추정으로 채웁니다. 메자닌 금액은 발행결정 기준이라 이미 전환·상환된 물량이 포함될 수 있습니다.
